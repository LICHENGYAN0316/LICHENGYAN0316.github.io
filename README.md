# Pluto · 随笔

A personal journal by Pluto, built with Astro and Fuwari.

Website: https://lichengyan0316.github.io/

## Development

Requires Node.js 22 and pnpm 9.14.4.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Publishing

Changes on `main` are checked, built with a search index, and deployed to GitHub Pages. Article drafts use `draft: true`.
