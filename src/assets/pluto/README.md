The homepage displays the full credit and active source/license links next to the image. Astro generates responsive WebP versions; the page crops the image with CSS and overlays a dark gradient and decorative animated stars. No scientific meaning is assigned to the decorative stars. The source is a Webb infrared observation rendered with mapped colours, not a visible-light photograph.

`public/pluto/avatar.svg` and `favicon.svg` are original stylised Pluto marks with a light heart-shaped region, not NASA photographs or scientific maps. The original Fuwari code remains covered by the repository LICENSE.
